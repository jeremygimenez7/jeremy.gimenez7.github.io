      How to Think Like an Analyst

      1. Observe unusual behaviour.
      2. Identify the source and destination.
      3. Determine which protocol is involved.
      4. Establish whether the activity is expected.
      5. Look for supporting indicators.
      6. Correlate with other security telemetry.
      7. Decide whether further investigation is required.
      An anomaly is a starting point for investigation, not proof of compromise.

      From Wireshark to this tool

      1. Open Wireshark.
      2. Capture traffic only in an environment you own or are authorised to monitor.
      3. Stop the capture.
      4. Export the packet dissections / packet list as CSV, retaining the column headings. Check whether you are exporting all packets or only displayed packets.
      5. Upload that CSV here.

      CSV is not a full capture. Encryption, NAT, missing fields, export filters, and Wireshark's protocol labels limit interpretation. This tool does not analyse malware or replace Wireshark, IDS, SIEM, or professional monitoring.

      Keep real captures outside OneDrive or other synced folders if you require local-only file storage. The application cannot control operating-system or browser-extension behaviour.
