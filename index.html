Phishing Email Analyser - Local, Explainable Email Triage

Static web app  ·  Security domains: Phishing & Social Engineering, Detection Engineering, Security Awareness

Built an educational triage tool that scores a pasted email from 0 to 100 against 49 warning-sign checks and shows exactly how that number was reached. It looks for urgency and pressure language, account-suspension threats, password and MFA-code requests, gift-card and bank-detail-change requests, look-alike, shortened and raw-IP links, dangerous attachment types and macro instructions. Pasting raw headers unlocks SPF, DKIM, DMARC, Reply-To and display-name checks. Every point is traced back to the evidence that produced it, and the analysis runs entirely in the browser.

HTML / CSS / JavaScript 49 explainable checks SPF / DKIM / DMARC header parsing Link & look-alike domain analysis No dependencies Local-only, nothing uploaded

Network Traffic Triage Tool - Wireshark CSV Analysis

Static web app  ·  Security domains: Network Traffic Analysis, Detection Rules, Blue-Team Triage

Turns a Wireshark packet-list CSV export into an explainable network activity report using six transparent threshold rules and no AI or machine learning. The rules cover high packet volume, possible network and port scanning, high ICMP activity, high DNS activity and repeated source-to-destination communication. Thresholds are adjustable so a learner can see how a configuration change alters the result without changing the underlying evidence. Includes three fictional sample captures and a dependency-free browser test suite.

Wireshark CSV parsing 6 explainable detection rules Adjustable thresholds Fictional sample captures Dependency-free test suite Content-Security-Policy locked down

Windows Security Event Log Triage Tool - SOC-Style Log Analysis

Static web app  ·  Security domains: Log Analysis, Event Correlation, SOC Triage, Incident Investigation

Reads a Windows Event Viewer Security-log CSV export and produces a plain-English SOC triage report: what happened, why it may deserve investigation, what ordinary activity could explain it, and what to check next. Correlation rules link failed-then-successful logons, account creation followed by privileged group membership, audit-log clearing and encoded PowerShell. Every finding carries an itemised score with the reason for each point, and each one lists its legitimate explanations.

10 supported Windows Event IDs Event correlation rules Itemised, explainable scoring False-positive explanations CSV parsing hardened against injection Local-only, logs never uploaded
